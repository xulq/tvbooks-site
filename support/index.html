Import an EPUB导入 EPUB

  1. On Apple TV, open the library menu and choose Upload local EPUB files.在 Apple TV 书库打开菜单，选择“上传本地 EPUB”。
  2. Open the address shown on the television in a phone or Mac browser on the same local network.用同一局域网内的手机或 Mac 浏览器打开电视显示的地址。
  3. Enter the temporary six-digit code and choose one or more downloaded EPUB files. Download iCloud Drive files first when necessary.输入六位临时配对码，选择一份或多份已下载的 EPUB；必要时先下载 iCloud Drive 文件。
  4. Wait for validation, then return to the library and open the book. Leaving the upload screen closes receiving.等待校验完成，返回书库打开书籍。离开上传页面会关闭接收。

Remote controls遥控器操作

  • Right button or right swipe: next page. Left button or left swipe: previous page.右键或右滑：下一页；左键或左滑：上一页。
  • Up/Down: change text size; hold to repeat. Select: reading menu.上／下：调整字号，按住可连续调整；中心键：阅读菜单。
  • Short Play/Pause: contents. Hold Play/Pause: preview landscape/portrait; Select confirms, Back restores.短按播放暂停：目录；长按播放暂停：预览横竖屏，中心确认、返回恢复。
  • In the library, directional buttons choose a book, Select opens it, and holding Select opens book options.书库中方向键选书、中心打开、长按中心打开图书选项。

Common questions常见问题

Can every chapter fit on one screen?所有章节都能一屏读完吗？

No single layout fits every chapter. A short chapter can fit with suitable text and spacing; long chapters still paginate. Landscape supports one, two or three columns, with two as the default.

每屏容纳量取决于章节长度、字号、行距和方向。合适的短章节可一屏呈现，长章节仍正常分页。横屏支持一、二、三栏，默认两栏。

What does portrait mode require?竖屏模式需要什么？

A monitor you can physically rotate. TVBooks compensates the page for a 90° or 270° display rotation. tvOS system screens remain in the system orientation.

需要能够物理旋转的显示器。TVBooks 为显示器的 90° 或 270° 旋转补偿页面方向；tvOS 系统页面仍保持系统方向。

Which EPUB files are supported?支持哪些 EPUB？

DRM-free reflowable EPUB 2/3, up to 80 MiB per source file. Fixed layout and vertical writing are not supported. Some complex SVG, formula and publisher CSS content uses a simplified display; scripts do not execute.

支持无 DRM 的可重排 EPUB 2/3，单本原书最大 80 MiB。不支持固定版式和竖排文字。复杂 SVG、公式和部分出版社 CSS 使用简化显示；不执行书籍脚本。

Why has a downloaded book become unavailable?为什么已导入的书提示需要恢复原书？

tvOS can evict cached book files. Keep the originals and export a reading-state backup. Uploading the exact same EPUB restores the book cache while preserving saved progress and bookmarks.

tvOS 可能清理原书缓存。请保留源文件并导出阅读状态备份；重新上传完全相同的 EPUB 可恢复缓存并保留已保存的进度和书签。

Does TVBooks synchronize Apple Books progress?会同步 Apple Books 的阅读进度吗？

No. TVBooks maintains its own reading position. It does not access Apple Books’ private cloud service, import DRM purchases or synchronize its private progress format.

不会。TVBooks 独立保存阅读位置，不访问 Apple Books 私有云服务、不导入 DRM 购书，也不持续同步其私有进度格式。

Is iCloud required?必须使用 iCloud 吗？

No. The first public release uses local file transfer and local reading. Downloaded iCloud Drive files can be chosen in your browser’s file picker. An automatic cloud library is not advertised as part of this release.

不需要。首发公开版本使用本地文件上传与本地阅读。浏览器文件选择器可选择已下载的 iCloud Drive 文件；首发不承诺自动云书库同步。

Is TVBooks an Apple app?TVBooks 是 Apple 官方应用吗？

TVBooks is independently developed. Apple TV and Apple Books are Apple products. TVBooks takes inspiration from a calm reading experience and is not affiliated with or endorsed by Apple.

TVBooks 为独立开发产品。Apple TV 和 Apple Books 为 Apple 产品；TVBooks 以简洁阅读体验为目标，与 Apple 无隶属或背书关系。
